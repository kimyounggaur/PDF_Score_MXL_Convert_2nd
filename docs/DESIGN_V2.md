# V2 디자인 결정 기록

V2-13은 두 방향을 비교한 뒤, 사용자가 이 작업에서 요청한 “단계별 질문 없이 스스로 승인” 원칙에 따라 안 A를 채택했다.

## 안 A — 교정대 / Score Proof Desk (채택)

- 색: 악보 용지 `#F6F8FA`, 잉크 `#17232D`, 연필 `#596873`, 오선 `#BCC7D0`, 교정 파랑 `#245C9E`, 교정 빨강 `#B1304A`
- 글꼴: IBM Plex Sans KR. 본문과 수치 모두 같은 계열을 쓰되 굵기·크기·괘선으로 위계를 만든다.
- 원칙: 결과 확인이 주인공이다. 반복 카드 대신 교정지처럼 이어진 판면과 수평 괘선을 쓴다. 움직임은 업로드·변환 오선 진행률과 직접 조작에만 둔다.

```text
데스크톱                              모바일
┌ 제목 · 서비스 상태 ────────────┐    ┌ 제목 · 상태 ───────┐
│ 업로드 작업면      │ 사용 조건 │    │ 업로드 작업면       │
├────────────────────┴───────────┤    ├────────────────────┤
│ 작업명 · 상태 · 교정 메모       │    │ 작업명 · 상태        │
│ 〽 오선 진행률                  │    │ 〽 오선 진행률       │
│ 원본 PDF       │ 변환 악보      │    │ 원본 / 변환 탭       │
└────────────────────────────────┘    └────────────────────┘
```

악보의 흰 종이, 오선, 연필 메모, 파랑·빨강 교정 표시에서 형태와 색을 가져왔다. 크림색·세리프·테라코타 조합과 장식용 그림자·그라데이션을 피하고, 차가운 종이색과 산세리프 글꼴로 실제 작업 도구에 가깝게 조정했다.

## 안 B — 리허설 콘솔 (비채택)

- 색: 무대 흰색 `#FBFCFE`, 지휘 남색 `#172554`, 보표 회색 `#64748B`, 큐 코럴 `#C2413D`, 준비 초록 `#047857`, 선택 파랑 `#2563EB`
- 글꼴: Noto Sans KR. 상태와 동작을 굵은 숫자와 짧은 레이블로 빠르게 훑게 한다.
- 원칙: 여러 작업의 대기·진행을 한눈에 운영한다. 작업을 세로 큐로 압축하고 선택한 한 건만 상세 비교한다. 상태 변화가 정보 구조를 주도한다.

```text
데스크톱                              모바일
┌ 업로드 · 전체 큐 현황 ─────────┐    ┌ 업로드 ────────────┐
│ 작업 큐  │ 선택 작업 진행·결과 │    │ 상태별 작업 목록    │
│          │ 원본 ↔ 변환         │    │ 선택 작업 상세      │
└──────────┴─────────────────────┘    └────────────────────┘
```

리허설의 큐 사인과 지휘 흐름에서 출발했지만, 현재 규모에서는 일반 운영 대시보드처럼 보이고 원본 대 결과 검수보다 대기열을 과도하게 강조한다. 그래서 핵심 가치인 “변환 결과를 믿고 확인”하는 안 A를 선택했다.

## 품질 기준

- 360px에서 문서 가로 넘침 없이 파일명·버튼·상태가 줄바꿈된다.
- 모든 조작 요소에 눈에 보이는 키보드 초점이 있다.
- `prefers-reduced-motion`에서는 진행률과 스피너를 포함한 비필수 애니메이션을 제거한다.
- 본문·버튼·상태색은 WCAG AA 명도 대비를 유지한다.
- 기존 기능 문구와 `data-testid` 계약은 유지한다.
